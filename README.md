# QR & Barcode Scanner — Privacy Policy

Public hosting for the privacy policy of the **QR & Barcode Scanner** Android app
(`com.ehsan.qrscanner`), as required by Google Play.

**Live URL:** https://ehsanahmadkhan525.github.io/qr-scanner-privacy/

This repository is public only so GitHub Pages can serve the policy. The app's
source lives in a separate private repository.

> Keep this in sync with `PRIVACY_POLICY.md` in the app repo. If the app ever
